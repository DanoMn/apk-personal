# Historias de refinamiento de umbrales — v1

Tanda para **refinar los cortes entre estados** y **validar dos reglas**: (1) una
capa a 0 no colapsa todo el sistema si el resto está fuerte; (2) el superávit
localizado no rescata si el resto está bajo.

> Marcá con la **panza**. A propósito NO hay números del motor — queremos TU criterio,
> no el del engine.
