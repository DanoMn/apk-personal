Vocal: Design System (Especificaciones)

Este documento es la fuente de verdad (Source of Truth) visual para replicar la interfaz en Jetpack Compose con máxima fidelidad.

  • Estética "Paper/Orgánica": Evitar el estilo tecnológico frío. Sin bordes rígidos (0px border). Todo se separa usando sombras difusas multicapa (Drop Shadows suaves) para un efecto flotante y premium.
  • Paleta de Personalidad (3 colores base):
    • Base Oscura: #1F1E1D (Un carbón cálido y orgánico. No usar grises azulados ni negros puros).
    • Acento Cartón/Beige: #D3C7B6 (Para elementos secundarios o tarjetas inmersivas. Da la sensación de papel).
    • Acento Coral: #E66A53 (Para acciones primarias, subrayados y checkboxes. Sutil pero vibrante).
  • Tipografía: Títulos en Serif (Lora) para el toque de libro/humano. Texto y datos técnicos en Sans-Serif Geométrica (Outfit). Siempre usar text-wrap: balance en títulos.

Dashboard de Inicio (Tarjetas Flotantes)

Especificaciones: Las tarjetas no tienen border. La separación visual se logra con una sombra sutil box-shadow: 0 8px 32px rgba(0,0,0,0.2). Los checkboxes usan el color Coral (#E66A53) al activarse. Las transiciones de hover duran 0.3s ease para levantarse ligeramente, invitando a la interacción táctil.

Nota del sistema

Observa cómo los botones primarios usan el color cartón, y los acentos visuales usan el tono coral. Las fuentes de los títulos ahora son Serif para dar ese toque de "libro" o aspecto de dibujo humano.

Configuración de Capas (Iconos Definitivos)

Especificaciones Críticas para Replicación: Las Capas son el corazón de Vocal, por lo que sus íconos deben sentirse como "sellos" primarios y masivos, radicalmente distintos a los íconos de la UI.

  • Se respeta el trazo normalizado de 1.5px en todo el ecosistema.
  • Truco de Peso Visual (Interior, Social, Proyecto): Para dar la sensación de masa pesada sin engrosar la línea, se eliminaron los bordes redondeados (ángulos afilados) y se inyectaron núcleos sólidos gigantes que casi tocan el borde (ej. el rombo interior, el hexágono interior sólido).
  • Fluidez Primal (Cuerpo, Conducta, Casa): Se utilizan ondas, tiendas de campaña y bucles infinitos para dar sensación de flujo natural y refugio.

Iconografía UI Esencial

Especificaciones Críticas para Replicación: los íconos utilitarios no deben competir con las Capas. Lucide se usa cuando el símbolo ya respira con trazo fino; cuando el concepto es central y Lucide se siente genérico, se usa un símbolo propio con la misma retícula de 24x24.

  • Grosor estricto: 1.5px. Son ligeros y dejan respirar la interfaz.
  • Bordes y remates: Redondeados en iconos de UI. Los ángulos afilados quedan reservados para los sellos de las Capas.
  • Escala: Siempre 24x24 de viewBox. En botones se muestran a 22-24dp; en esta guía se amplían a 32px para revisión visual.
  • Regla de coherencia: si una señal pertenece claramente a una capa, reutiliza el sello de esa capa en versión pequeña. Si es navegación, ajuste o acción, usa icono UI ligero.

Iconografía de Señales y Estado

Estas señales aparecen en dashboard, tarjetas de resumen y estados calculados. Las señales por capa usan el sello de capa correspondiente; las señales transversales usan UI ligera, pero pueden tomar el truco de peso visual de las capas cuando necesitan sentirse más primarias.

Regla de peso visual para señales: no agregar bases, subrayados o adornos externos para "explicar" el símbolo. Si una señal queda débil, se le da masa desde adentro: relleno sólido, núcleo geométrico o contraste entre una figura sólida y un trazo fino. Sueño queda como referencia: luna sólida + estrella geométrica, sin línea de suelo.
